Overall very similar to [[AWS Lambda]]. It's a serverless event driven compute service that is trigger based. 
You place a program written in the plethora of languages that it supports (Python, Ruby, Java, .NET, Node.js etc.) and trigger it via:
1. HTTP requests
2. Database changes
3. Messages queues
4. File uploads
5. IoT inputs
6. Time trigger (CRON like scheduler)

# Use cases
1. Web API's
2. Scheduled tasks
3. Event driven data processing
4. Message processing
5. AI data pipelines (sending data to AI services)
