Azure has all the typical cost saving schemes of an enterprise cloud provider:
1. Pay as you go
2. [[Cloud Spot Instance Scheme]]
3. Resource reservations to save up to 72% of cost
4. Azure hybrid benefits (specific to Azure)

But there are specialized tools that can help you manage and optimize costs. The general thought process of cost optimization is like so:
1. Use the [[Azure Pricing Calculator]] to get a high level estimate
2. Use the [[Azure Cost Management Service]] to manage, monitor, forecast, even export costs to Power BI
3. Optimize as you go with monitoring tools and budget caps 
4. Optionally: use Azure advisor

# Factors affecting costs
1. Consumption
2. Subscription type
3. Resource level
4. Region
